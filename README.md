# 🌐 Implantació d'Aplicacions Web (IAW)

Repositori per al mòdul professional **Implantació d'Aplicacions Web (IAW)** del 2n curs de C.F.G.S. Administració de Sistemes Informàtics en Xarxa (ASIX) a l'**Institut TIC de Barcelona**.

Aquesta assignatura se centra en la instal·lació, configuració i administració de servidors web, el desenvolupament d'aplicacions del costat del servidor, la integració amb bases de dades i el desplegament de gestors de continguts (CMS).
